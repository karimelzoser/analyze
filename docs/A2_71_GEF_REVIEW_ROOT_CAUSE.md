**Important:** The original file contents and client documents are private user uploads; do not commit them into this repository. Values below are transcribed diagnostic observations, not lab-confirmed USCS identifications.

## Root causes

1. The application used a four-window vote to decide whether a PRE sounding was VERIFIED. Engineers requested a **defined PRE rolling mean of 3 samples**; applying 1,5,7 as sensitivity investigations cannot invalidate the measured primary-run result. B238/B268/B271 were incorrectly converted to REVIEW from otherwise recorded interval evidence.
2. When the last qualifying 0.05-0.09m interval had separately rounded boundaries equal at **0.10m display precision**, the app discarded the interval and blanked the summary. B229/B239/B255/B276 were affected. Correct approach: preserve measured start/end and use **0.01m precision** where required, with clear precision metadata. Never fabricate 0.10m from a thinner observed interval.
3. **B253:** a preliminary 0.27m sounding and a later 6.09m sounding share the same coordinates, elevation, and test date. **B256:** a preliminary 0.56m sounding and a later 5.81m sounding share their coordinates/elevation/date. These are partial/aborted attempts followed by full investigations; they must be retained as separate source-audit records, not treated as contradictory full-depth strata interpretations.
4. Most soundings end in a roughly 0.1m zero-sleeve-friction tail. It remains **UNKNOWN**: never extend fine-grained layers through it, and never confuse measurement dropout with classification REVIEW of otherwise valid earlier data.

## New map contract

- **2D:** user-selected depth BGL with sand-like, transitional, silt-like and clay-like categorical color fields, interpolation only within locally supported survey triangles, site boundary clipping, and visually distinct NO COVERAGE.
- **3D:** actual x/y coordinates and RL, separate observed soil-classification **colored prisms** at each CPT; explicitly labeled symbolic footprints. Offline HTML supports soil categories, depth clipping, rotation, zoom and evidence-bounded interpolated 3-point wedges as an optional **inferred** layer, not an observed geologic solid.
- **Excel:** embed multiple 2D soil-depth maps and 3D geological column model inside the single output workbook; no points-only default.
